Internet and Web Definitions

Internet

The internet is a globally interconnected system of computer networks. It uses a protocol called TCP/IP which helps to facilitate communication between devices.

Web

If highways were the internet, the web is the vehicles that brings data and people onto these information highways. The web is a system of documents,pages, and other resources that can be accessed and shared by others.

How are the Internet and Web different?

Comparing roads to the web and internet is a tricky anology. Where the road is physical like the internet, the web is a collection of all things digital. It is a way to access things on the internet.

ASCII and Unicode

ASCII and Unicode are types of standard systems that computers use. ASCII is a representation for text that computers can use. Unicode is universal encoding that helps find characters in many languages.

What is UTF-8

This is a format that translates Unicode and ASCII to a language that computers are able to read. Binary. So, it takes everything from ASCII to Unicode.

URL

URL is a unique address that websites use. It helps to identify and access resources on the internet. URL stands for Uniform Resource Locater.

Domain Name

The domain name is a component of the url. It is the human readable portion of the url. Examples are google.com, yahoo.com, amazon.com, and so forth.

HTTP

HTTP is a protocol for the WWW that is used to transfer information. It is used to transfer data to networked devices.

HTTPS

This a protocol that encrypts and secures data being tansferred over the internet. It has TLS encryption that protects data between a web browser and website.

IP Address

An IP address is a unique internet protocol address assigned to IoTs and devices connected to the internet.

DNS

This acts as a catalogue that helps keep tracck of ip addresses. DNS translates the domain to a ip.

W3C Recommendations

It is a standard that is given for all things that have HTML, CSS, and XML. It is given after things have been thoroughly tested.

XML, XHTML, HTML, HTML5

These are all languages used in markup. So they use tags to help manage data for a website.
